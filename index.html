How the checks work

In the tables: formal = statement formally verified · recomputed = answer recomputed · numeric = numerically checked · model-reviewed = reviewed by a model only. Parts that only ask for a definition or a statement from memory are not counted.

A passing Lean proof establishes the conclusion; it does not certify each step of the written solution in the PDF.

Each released chapter lists every part and its check in checks/<course>-ch<nn>/report.md (lean = statement formally verified, sympy = answer recomputed, numeric = numerically checked, reviewed-only = reviewed by a model only, na = definition recall).

LabelWhat was checkedWhat was not checked
Statement formally verifiedThe conclusion of the part has a proof accepted by Lean 4 with Mathlib.Each step of the written solution in the PDF.
Answer recomputedAn independent script recomputed the final value or expression from the question's conditions and obtained the same answer.The written explanation of intermediate steps.
Numerically checkedThe equality held in random numerical examples.The general case.
